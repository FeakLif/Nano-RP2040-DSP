# UNET

Program that translates a proprietary protocol to a public standard

# Installation

1. [Download](https://code.visualstudio.com/) and install official Microsoft Visual Studio Code. PlatformIO IDE is built on top of it
2. Open VSCode Package Manager
3. Search for the official ```diff-`platformio ide``` [extension](https://marketplace.visualstudio.com/items?itemName=platformio.platformio-ide)
4. Install PlatformIO IDE
5. Fetch this repo

After opening this repo in VSCode PlatformIO shuould automatically initialize and fetch all dependencies, in the end you should have these contents in the worksapce bottom bar where 'tick' is Build command and 'arrow' is Flush

## Note

# *That `unet.pio.h` header file, which contains helper functions provided by pico-sdk, is not included as it is generated by your compiler. It will appear after first Build run.
