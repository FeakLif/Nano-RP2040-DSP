# UNET

Program that translates a proprietary protocol to a public standard

# Installation

1. [Download](https://code.visualstudio.com/) and install official Microsoft Visual Studio Code. PlatformIO IDE is built on top of it.
2. Open VSCode Package Manager.
3. Search for the official `platformio-ide` extension ([Marketplace Link](https://marketplace.visualstudio.com/items?itemName=platformio.platformio-ide)).
4. Install PlatformIO IDE.
5. Fetch this repo.

After opening this repo in VSCode, PlatformIO should automatically initialize and fetch all dependencies. In the end, you should have these contents in the workspace bottom bar where 'tick' is the Build command and 'arrow' is Flush.

/assets/images/screen.png

If not then tap the PlatformIO icon on the left sidebar to start initializing.

## Note

* That `unet.pio.h` header file, which contains helper functions provided by pico-sdk, is not included as it is generated by your compiler. It will appear after the first Build run.
* PlatformIO and PIO are not same things, PlatformIO is the framework and PIO is Programmable IO block that executes small, deterministic assembly programs independently of the main Arm Cortex-M0+ CPU cores.
